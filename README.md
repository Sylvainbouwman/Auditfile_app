# Auditfile Analyzer

Tool voor analyse van Auditfiles (XAF).

## Functionaliteiten

- BTW-analyse en drilldowns
- Analyse per BTW-code
- Grootboekanalyse
- Debiteuren- en crediteurenanalyse
- Logische controles op periodiciteit
- Trendanalyse tussen jaren
- Risicosignalering en reviewpunten

## Technologie

- Python
- Streamlit
- Git / GitHub

## Toekomstige uitbreidingen

- AFAS-koppeling
- Exact-koppeling
- Realtime monitoring
- AI-gedreven dossierreview
